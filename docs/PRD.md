# Product Requirement Document (PRD)

## Problem Statement
MedWave addresses the lack of healthcare access in remote villages by providing a voice-based medical consultation service.

## Target User
Individuals in remote villages without reliable internet access seeking medical advice via simple phone calls.

## Core Features for MVP
- Voice-based medical consultation service
- Phone call connectivity with healthcare professionals
- Reliable medical advice delivery without requiring internet

## Out of Scope
- Video consultations
- Mobile app or web interface requirement for patients
- Advanced online prescription management
